\section{Постановка задачи}
\label{sec:problem}
Пусть $D_{\rm tr}=\{d_1,\ldots,d_m\}$ --- обучающая коллекция, а $d=(w_{d0},\ldots,w_{d,L_d-1})$ --- последовательность токенов документа. По $D_{\rm tr}$ строятся словарь $V$ и частоты слов $f_w>0$; число тем $T$ задано. Для оценивания выделены непересекающиеся с обучением коллекции $D_{\rm ref}$ и $D_{\rm test}$: первая используется для внешней когерентности, вторая --- для восстановления слов. Частотная матрица $X\in\mathbb N_0^{m\times|V|}$ содержит счётчики слов. Порядок токенов и границы документов нужны для вычисления локального внимания.

В пределах одного корпуса предполагается независимость документов; зависимости между токенами учитываются через их окружение. Модель задаёт условное распределение слова по локальному контексту. Метки категорий используются только при отборе документов. Предобработка, ограничения длины и число тем одинаковы для сравниваемых методов. Качество восстановления оценивается на словах из $V$ с отдельным учётом покрытия тестового словаря.

Искомая матрица $\Phi\in\mathcal S=\{A\in\mathbb R_+^{|V|\times T}:\sum_t A_{wt}=1\}$ содержит вероятности $p(t\mid w)$. Соответствующие вероятности слов внутри темы $B_{wt}=p(w\mid t)$ получаются частотным взвешиванием. При фиксированных весах внимания $a_{ij}$ модель задаётся соотношениями
\begin{equation}
 B_{wt}(\Phi)=\frac{f_w\Phi_{wt}}{\sum_v f_v\Phi_{vt}},\quad
 \theta_{it}(\Phi)=\sum_{j\in\mathcal C(i)}a_{ij}\Phi_{w_jt},\quad
 p_\Phi(w\mid\mathcal C(i))=\sum_t B_{wt}(\Phi)\theta_{it}(\Phi).
 \label{eq:model}
\end{equation}
Множество $\mathcal C(i)$ содержит до пяти соседних позиций с каждой стороны в том же документе; $a_{ii}=0$, $a_{ij}\geq0$, $\sum_j a_{ij}=1$. До нормировки $a_{ij}\propto0.6(1-0.6)^{|i-j|}$ при $1\leq|i-j|\leq5$. Рассматриваются позиции с непустым контекстом и темы с положительной частотной массой.

Для обучения используется локальный составной критерий
\begin{equation}
 \mathcal L_{\rm loc}(\Phi)=-\sum_{d\in D_{\rm tr}}\sum_{i=0}^{L_d-1}
 \log p_\Phi(w_{di}\mid\mathcal C_d(i)).
 \label{eq:loss}
\end{equation}
Контексты перекрываются, поэтому этот критерий не является логарифмом совместного правдоподобия документа. Согласование с учителем задаётся штрафом $K(\Phi;Q)=\sum_w\KL(q_w\Vert\Phi_w)$, где строки $Q$ --- распределения тем для слов. Матрица $Q$ строится по $D_{\rm tr}$ и остаётся фиксированной вместе с кодировщиком.

Гиперпараметры выбираются на предварительной серии и затем фиксируются. Контроль основан на повторном отборе обучающих документов при общих $D_{\rm ref}$ и $D_{\rm test}$. Основной показатель --- перплексия восстановления скрытых слов в $D_{\rm test}$; дополнительно оцениваются NPMI на $D_{\rm ref}$, покрытие словаря и время работы. Искомое решение --- допустимая матрица $\widehat\Phi$. Для её получения применяется конечная EM-подобная процедура AARTM с инициализацией из $Q$ и KL-поправкой; нахождение глобального минимума не гарантируется. Задача регуляризованного оценивания имеет вид
\begin{equation}
 \widehat\Phi\ \in\ \underset{\Phi\in\mathcal S}{\arg\min}
 \left[\mathcal L_{\rm loc}(\Phi)+\lambda
 \sum_{w\in V}\sum_{t=1}^{T}q_{wt}\log\frac{q_{wt}}{\Phi_{wt}}\right],
 \qquad\lambda=0.1.
 \label{eq:argmin}
\end{equation}
