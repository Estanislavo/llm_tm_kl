\section{Введение}
Тематические модели описывают документы распределениями по темам, а темы --- распределениями по словам~\cite{blei2003}. Рассматриваемая модель AARTM дополняет аддитивную регуляризацию~\cite{vorontsov2015} локальным вниманием к соседним словам. На малых коллекциях ей может не хватать данных для выявления семантических связей.

В работе предлагается использовать предобученную языковую модель как фиксированного учителя AARTM. Распределения тем, полученные из контекстных представлений фрагментов, задают инициализацию и KL-регуляризатор. Перенос знаний в тематические модели исследовался ранее~\cite{hoyle2020}; здесь проверяется его применение к AARTM без дообучения кодировщика. Методы сравниваются по перплексии, когерентности и времени работы.
