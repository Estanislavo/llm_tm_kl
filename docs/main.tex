\paragraph{Ключевые слова.} Тематическое моделирование; AARTM; контекстные эмбеддинги; фиксированный учитель; KL-регуляризация; перплексия; когерентность.
\paragraph{Основные результаты.}
\begin{itemize}
\item Распределения тем для слов строятся из контекстных представлений фрагментов.
\item Один фиксированный учитель задаёт инициализацию и KL-согласование AARTM.
\item На пяти малых коллекциях completion PPL снижается в среднем на 7,40\%; внешний NPMI не показывает общего роста.
\end{itemize}
