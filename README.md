# llm_tm_kl

Согласование трансформерных и тематических эмбеддингов через KL-регуляризацию

Что делаю : тематические модели с механизмом внимания (AARTM) все ещё могут плохо работать на коллекциях документов по сравнению с трансформерами. Особенно это может быть заметно на малых коллекциях, где модели не хватает данных для построения хорошей матрицы фи. Целью работы является улучшение результатов тематических моделей через соотношение их с трансформерами на этапе обучения без потери преимущества сильного выигрыша тематических моделей по времени

Зачем : плохие результаты тематических моделей

Как буду измерять успех: перплексия, когерентность, время работы и другие
