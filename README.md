# Фиксированный контекстный учитель для AARTM

**Готовый текст:** [PDF](docs/main.pdf) · [LaTeX](docs/main.tex) · [библиография](docs/references.bib) · [соответствие требованиям m1p.org](docs/M1P_REQUIREMENTS.md).

Работа исследует перенос семантики замороженного MiniLM в тематическую модель AARTM. Контекстные представления фрагментов задают фиксированные распределения тем для слов `Q = q(t|w)`. Они используются для инициализации и KL-согласования; трансформер не дообучается, дополнительные обучаемые параметры внимания не вводятся.

## Подтверждённые результаты

- На пяти малых коллекциях, 10/30/50 обучающих документов, seed 10–12: среднее парное снижение document-completion PPL **7,40%**, улучшение в **42/45** парах. Оценка относится к словам обучающего словаря.
- Внешняя NPMI меняется в среднем на **−0,00273**, улучшается в 17/45 парах. Общего улучшения интерпретируемости эти результаты не показывают.
- На 27 общих парах абляций полный метод даёт 5,34% снижения completion PPL, только инициализация — 5,27%. Основная часть эффекта объясняется инициализацией.
- На 99 049 документах arXiv training PMI выше базовой AARTM во всех 20 парах; при 500 темах отношение средних составляет **2,03**. В этой серии нет отложенного arXiv test.

Сравнение с FASTopic и CombinedTM относится к сохранённым настройкам. FASTopic обучен 30 эпох и показал недообучение в дополнительной проверке; CombinedTM использует адаптацию с MiniLM. Сквозное время от сырого текста не сопоставлено, поэтому общее превосходство по качеству или скорости не заявляется.
